## 다익스트라에서 경로 갱신을 한다는 의미는 최적의 경로를 찾는다는 것이지, "돌아가지 않는 경로를 찾는다"라는 의미와는 본질적으로 다르다.

인접노드를 거쳐 다른 인접노드로 가는 거리를 갱신하는 과정이다.

```scss
A ──2── B ──3── C
│             │
└──────10─────┘
```

인접노드를 거쳐 가는 것이 돌아가는 것은 아니고, 거리를 따져서 가장 최적의(효율의) 거리를 갱신하는 과정이다.
- visited / for : 출발점이 특정 1지점일 경우
- pq : 출발점이 여러 지점일 경우

이 갱신 과정이 현재까지 알려진 가장 작은 가중치를 시작으로 하는 것은 동일하고, 문제에 따라
- 그 가중치를 시작 기준으로 다음 노드까지 가는 경로에서 최대의 가중치를 구하느냐
- 최소의 가중치를 구하느냐

이것이 달라진다.

> 최대의 가중치, 최소의 가중치를 구하든 가장 마지막 과정에서 "최적의 경로"를 구하는 것은 변하지 않는다.

즉, distance는 특정 시작점으로 부터 해당 거리로 가는 가장 최적의 해라는 것은 변하지 않는다.
- 가중치가 이미 계산되어 도출된 가중치보다 더 크다면 해당 가중치는 계산이 이루어질 필요가 없다(최적의 해가 아니기에).
